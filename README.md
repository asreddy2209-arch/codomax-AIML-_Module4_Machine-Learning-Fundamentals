# 🌸 Module 4 — Iris Machine Learning

This project demonstrates a basic **Machine Learning classification workflow** using the famous **Iris dataset** and Python's **Scikit-learn** library.

The project is implemented in a Jupyter Notebook and can be run using **Google Colab**.

---

## 🎯 Project Objective

The objective of this module is to understand the basic Machine Learning workflow:

* Load a dataset
* Explore the dataset
* Split data into training and testing sets
* Train a Machine Learning model
* Evaluate the model
* Visualize predictions using a confusion matrix
* Make predictions on a new sample

## 🌸 Iris Dataset

The project uses the **Iris dataset**, a well-known dataset for Machine Learning classification.

The dataset contains measurements of Iris flowers and is used to classify flowers into different species.

The notebook loads the Iris dataset automatically.

---

## 🔄 Machine Learning Workflow

```text
Iris Dataset
     ↓
Explore Dataset
     ↓
Prepare Features & Target
     ↓
80/20 Train-Test Split
     ↓
Train Logistic Regression
     ↓
Predict Test Data
     ↓
Evaluate Accuracy
     ↓
Confusion Matrix
     ↓
Predict New Flower
```

---

## 🤖 Machine Learning Model

### Logistic Regression

The project uses **Logistic Regression** as the classification algorithm.

The model is trained using the training portion of the Iris dataset and then evaluated using previously unseen test data.

---

## 📊 Train-Test Split

The dataset is divided into:

```text
80% → Training Data
20% → Testing Data
```

The training data is used to teach the model, while the testing data is used to evaluate how well the model performs on unseen examples.

### Why is testing on unseen data important?

Testing on unseen data helps check whether the model has learned useful patterns instead of simply memorising the training examples.

---

## 📈 Model Evaluation

The notebook evaluates the Logistic Regression model by reporting:

* **Accuracy**
* **Confusion Matrix**

The confusion matrix helps visualize how many samples were classified correctly and incorrectly for each class.

---

## 🔮 New Flower Prediction

After training and evaluating the model, the notebook uses the trained model to predict the class of a **new Iris flower sample**.
